# 当前项目笔记

这个项目现在有三块基础能力：

- WorkingMemory：保存当前会话里的关键事实，供当前窗口短期使用
- WindowMemory：退出聊天窗口时，由 LLM 从该窗口历史中提炼记忆快照
- GlobalMemory：由 LLM 合并 WindowMemory 和已有全局记忆，生成跨窗口可用的长期记忆

它们和 RAG 的区别是：

- Memory 偏向用户自身信息、偏好、习惯、项目背景和交互历史
- RAG 偏向外部知识库文档里的事实和资料
- Qdrant 只用于知识库文档检索，不用于个人长期记忆

当前问答流程会先由 LLM 决定是否需要走 ReAct。普通聊天、文档解释和记忆类指令可以直接回答；天气、地图、周边搜索、计算等需要工具的任务才进入 ReAct。
